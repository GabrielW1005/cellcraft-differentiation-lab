# Cellcraft: Differentiation Lab

[Play Cellcraft](https://gabrielw1005.github.io/cellcraft-differentiation-lab/)

An original browser game and matching two-page worksheet for seventh-grade life science. Explore six specialized cells, play function challenges, and connect cells to tissues, organs, systems, and an organism.

## Run

Open `index.html` or serve this directory as a static website. GitHub Pages can publish this repository from the main branch and repository root. No installation or server is required.

## Activities

- Worksheet trail with ten matching prompts and a printable two-page student worksheet.
- Six cell missions, a free exploration lab, three tissue towers, and a field guide.
- Light and navy dark themes, touch controls, keyboard support, and reduced-motion support.
- Progress stays in the browser. Download and load a JSON progress file to continue on another device. Written responses are recorded, not automatically graded.

This is an original supplementary resource aligned with McGraw Hill/Glencoe grade-seven concepts, not an official McGraw Hill product. Cell diagrams, developmental timing, and gene-program controls are simplified teaching models. The teacher answer key is distributed separately and is not included here.
